# native-cli-adaptation 术语

| 术语 | 本 change 中的含义 |
|---|---|
| 规范命令 | `siyuan-cli`。SKILL、文档、帮助、示例和错误提示用它调用本项目。 |
| 兼容别名 | 本项目继续发布的 `siyuan` bin，用于 SiYuan 3.7.0 之前的环境和既有调用；在新版环境中可能与官方命令发生 PATH 竞争。 |
| 原生 CLI | SiYuan 3.7.0 起随内核分发的官方 `siyuan` 可执行程序，不指本项目的兼容别名。 |
| native backend | N2 可能采用的内部子进程调用路径，仅允许承载选定的只读能力。 |
| N1 | 最小可用的命令入口兼容改造，可独立验收和发布。 |
| N2 | 在 N1 之后选择性继承新版原生 CLI 与相关 API 能力的完整工作包。 |
